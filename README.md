# Task Organizer

A lightweight task organizer built with HTML, CSS, and vanilla JavaScript.

## Use

Open `index.html` in a browser. Create tasks with a title, optional details and due date, and a priority. Use the task list to edit, complete, filter, search, or delete tasks.

Tasks are saved in the current browser using `localStorage`. This is a static front-end app: data is not shared between browsers and is not stored in a server-side database.
